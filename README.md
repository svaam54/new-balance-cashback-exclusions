## Why cashback sometimes doesn't track (and how to make sure yours does)

Tracking failures are the real weakness of every cashback portal, and the fix is mostly browser hygiene. These are the documented culprits:

- **Safari.** TopCashback's own New Balance page warns that Safari can't guarantee tracking. Use Chrome or another supported browser.
- **Cookie overwriting.** The most recent affiliate cookie wins. If you wander around the New Balance site or click another deal site *before* going through TopCashback, you lose the claim. Click through from TopCashback, then shop.
- **Broken sessions.** Starting the purchase in one browser session and finishing hours later, or switching to the retailer's app mid-checkout, can sever the tracking cookie. Same browser, same session, start to finish.
- **Ad blockers and VPNs.** They can silently strip the tracking code. Disable them for the purchase and accept tracking cookies.
- **Sponsored ads.** On the retailer's site, clicking a sponsored product link can reset attribution. Use the main navigation.

Experienced users on Trustpilot add one more habit worth stealing: screenshot the order confirmation.
